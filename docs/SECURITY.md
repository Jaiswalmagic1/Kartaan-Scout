# Security
- Capture only rendered DOM from the active tab after explicit click.
- Do not collect credentials, cookies, tokens or hidden APIs.
- Treat page content and AI output as untrusted.
- Store captures in Chrome local storage; no upload service is included.
- Export/AI handoff requires user action.
- Keep the proposal allowlist conservative.
- Never click final publish/submit controls automatically.
- Do not claim live marketplace validation until a human has tested an authorized account.
